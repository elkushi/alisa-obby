# Обби Алисы — как поменять текст

Всё, что можно переписать, лежит в одном месте.

## Быстрый способ (без пересборки)
Открой `alisa_obby.html`, найди `const CFG = {` (примерно 60% файла, ищи по слову `CFG`).
Меняешь текст между кавычками — сохраняешь — открываешь файл в браузере. Всё.

## Правильный способ (если хочешь пересобрать)
1. Правишь `src/template.html` (там тот же блок `CFG`)
2. Запускаешь:  `python3 build.py`
3. Получаешь свежий `alisa_obby.html`

## Что где в CFG

| Поле | Что это |
|---|---|
| `her` / `him` | имена (в карточке игрока и в подписи) |
| `introTitle` | заголовок стартового экрана |
| `introText` | текст под заголовком |
| `stageMsg[0..3]` | сообщение после 1-го, 2-го, 3-го и 4-го этапа |
| `finalTitle` | заголовок финального экрана |
| `finalText` | главное поздравление |
| `finalSig` | подпись |
| `flipSay` | что Алиса кричит, когда крутит сальто |
| `idleSay` | что пишет Мустафа, если она стоит на месте |

`stageMsg` — это как раз место под ваши личные шутки и даты.
Четыре сообщения: после этапов 1, 2, 3 и 4. После 5-го — финальный экран.

## Файлы
- `alisa_obby.html` — игра целиком, один файл, картинки внутри. Можно слать как есть.
- `src/template.html` — исходник без картинок
- `sprites/` — вырезанные спрайты
- `extract.py` — вырезает спрайты из исходных картинок
- `build.py` — вшивает спрайты в HTML
- `serve.py` — локальный сервер для проверки: `python3 serve.py` → http://127.0.0.1:8731/alisa_obby.html

## Музыка

Музыка не файл — она генерируется в браузере, поэтому ничего не грузится и не тормозит.
У каждого этапа свой лад и темп, ищи `MUSIC_BY_STAGE`:

```js
const MUSIC_BY_STAGE = [
  {root:60, scale:MAJ, bpm:108},   // 1 — до мажор, спокойно
  {root:67, scale:MAJ, bpm:118},   // 2
  {root:57, scale:MIN, bpm:128},   // 3 — минор, тревожно (лава)
  {root:62, scale:MAJ, bpm:120},   // 4
  {root:60, scale:MAJ, bpm:126},   // 5 — финал
];
```

- `root` — нота (60 = до). Больше число — выше.
- `scale` — `MAJ` (весело) или `MIN` (тревожно).
- `bpm` — темп.

Музыка сама нарастает: сначала бас, дальше арпеджио, к концу этапа — мелодия и барабаны.
На смерти приглушается, на финале выключается и играет фанфара.
Кнопка 🔊 внизу справа (или клавиша `M`) выключает и музыку, и звуки.

## Управление

- Стрелки / `A` `D` — движение
- `Пробел` — прыжок, **два раза подряд — сальто** (второй прыжок в воздухе)
- `R` — начать этап заново
- `M` — звук


## Реплики

**Сальто.** Второй прыжок в воздухе — Алиса делает сальто и над её головой
появляется облачко с репликой из `CFG.flipSay`. Первая строка списка звучит
всегда первой, дальше — случайная. Чаще одного раза в 3.5 секунды не появляется,
чтобы не мельтешило.

**Простой.** Если она сделала первый шаг, а потом 5 секунд стоит и ничего не
нажимает — слева внизу появляется сообщение от Мустафы с его аватаркой,
строки берутся по кругу из `CFG.idleSay`. Следующее — не раньше чем через 12 секунд.

Добавляй в списки сколько хочешь строк — они просто перебираются по очереди.

В любой реплике можно написать `{him}` или `{her}` — подставятся имена
из `CFG.him` / `CFG.her`. Например `'{him}, ты видел сальто?!'`
превратится в «Мустафа, ты видел сальто?!». Так что если поменяешь имя
в одном месте — оно поменяется везде.


## Вопросы между этапами

Чтобы перейти на следующий этап, Алиса отвечает на 3 вопроса.
Неправильных ответов нет — на любой вариант Мустафа отвечает своей репликой.

Всё лежит в `CFG.gates`, ключ — номер пройденного этапа:

```js
gates: {
  1: {type:'quiz', qs:[ {q:'Вопрос?', opts:[ {a:'Вариант', r:'Ответ Мустафы'} ]} ]},
  2: {type:'quiz', ...},
  3: {type:'irl'},      // задание в комнате
  4: {type:'quiz', ...},
}
```

`q` — вопрос, `a` — что видит Алиса, `r` — что Мустафа отвечает на этот вариант.
Вариантов может быть сколько угодно, вопросов тоже.

## Задание в комнате

**Часть 1 — после 3-го этапа (подарок):**
карточка «Стоп. Просто так подарок не отдаётся.» → **видео** → 90 секунд на поиск подарка

**Часть 2 — после 5-го этапа (ключ):**
она доходит до Мустафы с подарком, пауза на подиум → 90 секунд на поиск ключа →
«Согласна?» (кнопка «Нет» не работает) → задание → «Ключ твой» → финал

Тексты — в `CFG.irl`. Таймеры — `hunt.secs` и `key.secs`.
Таймер тикает каждую секунду, последние 10 — громче и краснеет.

### Видео

Видео **одно**. Положи любой `.mp4` в `game/video/` и запусти `python3 build.py` —
оно вошьётся прямо в HTML, работает без интернета.
Если видео нет — шаг просто пропускается, игра идёт дальше.

Сжатие (вся страница должна остаться меньше 16 МБ):

```bash
ffmpeg -i original.mov -vf "scale=-2:720" -c:v libx264 -crf 30 -preset slow -pix_fmt yuv420p -c:a aac -b:a 96k "game/video/1.mp4"
```

Вертикальное видео с телефона поддерживается — плеер подстраивается под формат.

## Тестовый режим

В `CFG` есть `TEST`. Пока он `true`:
- оба таймера по 10 секунд
- внизу экрана панель: ◀ этап · этап ▶ · задание · ключ
- красная плашка «ТЕСТ · 10 С»

**Перед показом поставить `TEST: false` и пересобрать.**
